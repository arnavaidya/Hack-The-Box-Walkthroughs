# Hack The Box Writeups

A collection of my Hack The Box (HTB) machine writeups, walkthroughs, and notes created for learning, revision, and knowledge sharing.

## Disclaimer

These writeups are intended for educational purposes only and are based on retired Hack The Box machines, Starting Point machines, or lab environments specifically designed for cybersecurity training.

All techniques demonstrated were performed in authorized environments. Do not attempt to use these techniques against systems without explicit permission.
